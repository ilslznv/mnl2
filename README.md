# manool — главная (MVP, десктоп)

Запуск: `node server.mjs` в этой папке → http://localhost:3010
(3D-голова манула — ES-модуль, через `file://` не откроется.)

## Сетка и размеры (сняты с jarcos.work)
- 8 колонок, поля 16px, гаттер 10px (`.grid` в `css/style.css`)
- базовый кегль `--u` = 0.8333vw (16px на 1920, 12px на 1440 и меньше), крупный — ×2
- все вертикальные отступы кратны `--u` (`--s-1 … --s-16`)
- клавиша **G** показывает/прячет сетку поверх страницы

## Анимации
- анимации работают и при выключенных «эффектах анимации» в Windows (настройку `prefers-reduced-motion` сайт не учитывает — так задумано)
- плавный скролл — свой, в `js/main.js` (`scroller`), без библиотек
- блюр боковых слайдов — заранее размытые картинки (`assets/img/hero-blur`, `hero-mid`), а не CSS-фильтр: так листание не тормозит.
  Если меняешь картинку слайда — нужно пересобрать и её размытые копии

## Что где
- `index.html` — разметка; буквы логотипа вшиты как отдельные `path` (для анимации)
- `css/style.css` — токены, сетка, все состояния
- `js/main.js` — слайдер, курсор, меню, анимации по скроллу
- `js/mascot.js` + `js/mascot/` + `js/vendor/three*` — голова манула из прошлой версии (`index.html` в корне)
- `assets/` — шрифт ABC Oracle, картинки в webp, логотип, иконка
